About me

परिचय
DP [Your photo]

I’m a software engineer who likes the whole path a request takes: from a Salesforce screen, through a .NET API, to an AI agent that decides what to do next.

At DealerMatix Technologies Pvt. Ltd., I build a scalable, multi-tenant business execution platform, turning real-world user requirements into AI-powered features that run real business operations. I also work on Salesforce solutions there, using Apex, Lightning Web Components and Flow. Most days that means designing APIs and data models in C#, and building integrations that don’t fall over.

Lately I’ve been building agentic AI: LLM-powered agents that call tools, read company data safely and hand off to a person when they should.
